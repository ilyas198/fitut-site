# Dossier des médias

Déposer ici les fichiers fournis par le comité d'organisation.

| Dossier | Contenu attendu | Format conseillé |
|---|---|---|
| `logos/` | Logo FITUT et logo ASAU | `.svg` + `.png` transparent |
| `accueil/` | 3 à 5 visuels du hero | JPG paysage, 2400 × 1350 px |
| `equipe/` | Portraits des membres | JPG carré, 800 × 800 px |
| `festival/` | Photos participants, lieux, compétition | JPG, 1600 px min |
| `carnaval/` | Photos du carnaval | JPG, 1600 px min |
| `editions/` | Un sous-dossier par édition : `18/affiche.jpg`, `18/galerie/…` | JPG, 1500 px min |
| `presse/` | Les 12 logos de médias | PNG transparent |
| `partenaires/` | Logos des sponsors | SVG ou PNG transparent |
| `og/` | Images de partage réseaux sociaux | JPG 1200 × 630 px |

**Nommage** : minuscules, sans accent ni espace. Exemple : `edition-18-affiche.jpg`.
